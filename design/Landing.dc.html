Turn sample JSON into real types in 25 languages.

quicktype Studio reads JSON, JSON Schema, TypeScript or GraphQL and writes models with serializers for TypeScript, Swift, Kotlin, Rust, Go, C# and more. It runs on your machine. Your data stays there.

Three ways to run it

Desktop app

One portable file for Windows. Every feature, including personal wording files, extensions and saving straight into your project folders.

Download

Self-hosted container

Run the web version on a server on your network and open it from any browser.

docker compose up -d

Appliance image

A small system image that boots straight into Studio. Flash it to a spare machine or import it as a virtual machine.

Appliance guide
If a feature does not work in the web version or on the appliance, download the desktop app. It is the only edition that can read files you drop on its window and run extensions. Get the desktop app
