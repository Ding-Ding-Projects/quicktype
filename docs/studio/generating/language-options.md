# Language options

Every option the quicktype engine exposes for the selected language appears in the options panel, with the engine's own description behind the info button.

## How to use it

Switches, menus and text fields are built from the language's option definitions, so new engine options appear automatically. Choices are remembered per language.

## When something goes wrong

An option value the engine rejects is reported as a generation problem; the previous code stays visible.

## Privacy and security

Options are stored locally with the rest of the workspace state.

## How to check it works

Toggle each option for a language and check the output changes accordingly.
