# Samples

Ready-made inputs covering JSON, JSON Schema and TypeScript so you can see output immediately.

## How to use it

Pick a sample and choose Use this sample; it replaces the current source and switches to Generate.

## When something goes wrong

The TypeScript sample needs the desktop app or the self-hosted server.

## Privacy and security

Samples ship with the app and contain no personal data.

## How to check it works

Use each sample and confirm the Generate tab updates.
