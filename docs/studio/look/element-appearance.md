# Per-element appearance

Most panels and controls can be restyled one by one: font (including fonts installed on your computer when the browser allows it), size, text colour, background and corner radius.

## How to use it

Right-click and choose Edit appearance, or Shift and right-click to open the editor directly. Reset this element removes the overrides.

## When something goes wrong

If the system font list is not available, the shipped fonts are offered.

## Privacy and security

Local settings only.

## How to check it works

Restyle an element, restart, then reset it.
