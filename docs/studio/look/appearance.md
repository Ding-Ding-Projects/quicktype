# Themes and appearance

Light, dark, high contrast or match the system, an accent colour, comfortable or compact density and a text size slider.

## How to use it

Settings, Appearance and Accessibility. Changes apply live.

## When something goes wrong

An invalid accent value is ignored and the previous colour stays.

## Privacy and security

Local settings only.

## How to check it works

Check every tab in each theme at 85% and 160% text size.
