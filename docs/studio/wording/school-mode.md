# School mode

One switch, shared by every app on this device that supports it, that keeps the interface in English with serious wording and turns off personal wording and the dim sum surprise.

## How to use it

Settings, Language and wording. Set a PIN when you turn it on; turning it off asks for the PIN. You can rename the mode, and every surface then uses your name for it.

## When something goes wrong

If the shared record cannot be read, the switch says so instead of pretending the mode is off.

## Privacy and security

This is a convenience lock, not a security boundary: deleting the shared record resets it. The PIN is stored only as a salted hash.

## How to check it works

Turn it on in one window and watch another running copy follow without a restart.
