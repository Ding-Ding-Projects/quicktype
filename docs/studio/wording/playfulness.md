# Playfulness levels

Two sliders, one for English and one for Cantonese, set how playful messages sound from 1 (fully serious) to 5 (most playful). Both start at 5.

## How to use it

Settings, Language and wording. Each slider has its own reset. A live sample error message shows the effect.

## When something goes wrong

The level changes voice only. Every message still says what happened, what is affected and what you can do, including errors and warnings.

## Privacy and security

No data leaves the device.

## How to check it works

Set each slider to 1 and 5 and trigger a success and an error message in each language.
