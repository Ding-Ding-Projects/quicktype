# File converter

Convert between JSON, YAML, CSV, TSV and URL query strings on your device.

## How to use it

Tools tab: choose From and To, paste, Convert, then Export.

## When something goes wrong

Malformed input is reported with the parser message and the previous result stays.

## Privacy and security

Conversion is local.

## How to check it works

Round-trip a JSON array through CSV and back.
