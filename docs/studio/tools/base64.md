# Base64 toolkit

Encode and decode Base64 text, including the URL-safe alphabet, with UTF-8 handled correctly.

## How to use it

Tools tab: Encode, Decode, URL-safe alphabet.

## When something goes wrong

Invalid Base64 is reported and nothing changes.

## Privacy and security

Local only.

## How to check it works

Encode text with accents and emoji, decode it back.
