# First-run setup

Five short steps the first time you open the app: welcome, favourite languages, appearance and language, sample data, and opening the workspace.

## How to use it

Back, Next and Skip this step are always available. Progress is saved after every step, so closing the window resumes where you left off. Settings, General, Run setup again restarts it.

## When something goes wrong

Skipped steps are remembered and simply use defaults.

## Privacy and security

Choices are local settings.

## How to check it works

Close the app on step 3, reopen it, and finish.
