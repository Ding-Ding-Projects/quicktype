# Tabs

Every destination is a tab, and every tab starts open. The strip docks to the left by default and can move to the right, top or bottom.

## How to use it

Right-click the strip for Open every tab, New tab and the dock edge. Drag tabs or press Alt+Shift with the arrow keys to reorder; pin tabs to keep them first. New tab (Ctrl+T) opens a searchable catalog of every destination.

## When something goes wrong

A tab you close stays closed after restarts and updates until you reopen it. Tabs added by an update open once.

## Privacy and security

Tab layout is a local setting.

## How to check it works

Fresh profile: every tab open in order. Close one, restart: still closed. Open every tab: all back.
