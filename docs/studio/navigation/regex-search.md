# Regex builder on every search

Every search box starts in plain text and has its own regex builder beside it: mode switch, ignore-case, multiline and Unicode flags, start and end anchors, and building blocks you can insert.

## How to use it

Press the .* button next to a search. Typing ^ or $ in the box turns the anchor switches on, and the switches rewrite the box, so both always agree.

## When something goes wrong

An invalid pattern is shown with the engine's message and leaves the previous results in place. Patterns over 2,000 characters are refused.

## Privacy and security

Searches run locally.

## How to check it works

Build an anchored pattern with the builder, edit it by hand, and check both stay in sync.
