# Context menus

Right-click anywhere for a menu that fits what you clicked: copy, paste and select all in text, tab actions on tabs, Edit appearance on styled elements, and the command palette everywhere. Each item shows the shortcut that really performs it.

## How to use it

Use the arrow keys to move and Esc to close.

## When something goes wrong

Items that cannot apply are shown disabled rather than hidden.

## Privacy and security

Clipboard access only happens when you choose Copy or Paste.

## How to check it works

Right-click text, a tab and a panel and check each menu.
