# Command palette

Ctrl+Shift+F opens one search over commands, places, live settings and labelled elements. Settings show their real controls in the results, so you can change them without leaving the palette.

## How to use it

Type to filter, Up and Down to move, Enter to run or jump, Space to toggle a switch, Esc to close. Choosing an element scrolls to it and highlights it.

## When something goes wrong

With no matches the palette says so.

## Privacy and security

Nothing is sent anywhere.

## How to check it works

Search for theme, toggle it in place, then jump to an element.
