# Changelog and docs

The Changelog tab shows what changed in each version, and the Docs tab carries these same articles offline with a regex-capable filter and suggested next articles.

## How to use it

Links between articles open inside the app.

## When something goes wrong

Articles are bundled with the app, so they match the version you run.

## Privacy and security

No network access is needed.

## How to check it works

Open every article from the Docs tab offline.
