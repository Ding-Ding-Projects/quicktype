# Local history and exports

Every successful generation and every settings change is recorded locally. Settings entries can be restored. Select entries to delete or export them as JSON, CSV, Markdown, HTML or text.

## How to use it

History tab. Deleting needs the two-key confirmation.

## When something goes wrong

History keeps the latest 300 entries.

## Privacy and security

Personal wording data and file details are never recorded or exported.

## How to check it works

Change a setting, restore it from history, export, and check the export contains no wording data.
