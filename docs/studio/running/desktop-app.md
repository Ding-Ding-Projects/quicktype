# Desktop app

The full edition for Windows, as an installer that updates itself or as one portable file.

## How to use it

Download it from the Download page. The installer checks for updates at start and every few hours, downloads them in the background and offers Restart to install update; you can choose Later.

## When something goes wrong

The portable file cannot update itself and says so in Settings, Updates.

## Privacy and security

The files are not code-signed, so Windows may warn about an unknown publisher. The app makes no network requests except the update check.

## How to check it works

Install, check About for the version, and check for updates.
