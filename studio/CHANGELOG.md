# quicktype Studio changelog

## Next release

- New look, Midnight forge: a dark glass workspace with a lime accent, Geist type, syntax-coloured editors with line numbers, coloured language tabs and a floating command bar. Light and high-contrast themes follow the same layout.
- Generate now shows the inferred types beside the output, built from the engine's own schema, and every option is a rich control with an explanation and its default.
- New JSON editor with Tree, Code, Split and Table views, inline editing, type switching, drag and drop, labelled undo and redo, regex find, JSONPath queries, schema validation, lenient import, sorting and clean-up, and a button that generates types from the document or one node.
- Tab groups with their own searches, per-tab and per-element appearance editing, a full colour picker, a logo editor, scheduled settings and a focus timer.
- The website now runs the complete generator and JSON editor in your browser on its Use it now page. TypeScript input there points to the desktop app or the container.

## 24.0.0 Studio, first release

- New desktop app, self-hosted container and appliance image built on the quicktype engine.
- Redesigned interface: left-docked tabs, a Ctrl+Shift+F command palette and a regex builder beside every search.
- English, Cantonese and bilingual wording, with independent playfulness levels.
- Personal wording files that stay on your device, plus a shared School mode.
- Local history with exports, a file converter, a Base64 toolkit and an extension manager.
